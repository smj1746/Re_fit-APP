## 📱 1. 프로젝트 배경 및 소개

### 🎯 개발 배경
- **홈트레이닝 문화의 대중화**: AI 발달로 인한 AI 기술 활용 홈트레이닝의 필요성 대두
- **운동 부상 방지의 중요성**: 올바른 운동 자세를 통한 신체건강 관리의 중요성 증가
- **개인화된 피트니스 수요**: 공간, 시간에 구애받지 않는 개인 맞춤형 피트니스 솔루션 필요

### 🚀 프로젝트 목표
> **AI 기반 자세 코칭 앱이 현대인의 홈트레이닝 필요성을 만족**

- **사용자 맞춤형 피드백**: AI 기반 자세 분석 기능을 통해 개인별 운동 피드백 제공
- **건강한 사회 구현**: 운동 습관 개선을 통한 개인의, 나아가 사회 전체의 건강증진 기여
- **접근성 향상**: 언제 어디서나 이용 가능한 스마트 피트니스 서비스

### 🛠️ 기술 스택

#### 개발 환경
- **IDE**: Android Studio
- **언어**: Kotlin/Java  
- **플랫폼**: Android (API 34, Android 14)
- **테스트**: Pixel 8 에뮬레이터

#### AI/Computer Vision
- **MediaPipe**: Google의 실시간 포즈 인식 프레임워크
- **TensorFlow Lite**: 모바일 환경 최적화 AI 모델
- **CameraX**: Android 공식 카메라 API
- **Pose Estimation**: 17개 신체 키포인트 검출

#### UI/UX
- **Material Design**: 구글 디자인 가이드라인
- **XML Layout**: Android 네이티브 UI
- **Custom Views**: 포즈 스켈레톤 시각화

## 🎮 2. 프로젝트 주요 기능 소개

### 📲 구현 완료된 화면

#### 🏠 **홈 화면**
- 직관적인 메인 인터페이스
- 좌측 상단: 📅 캘린더 아이콘 (운동 기록 조회)  
- 우측 상단: ⚙️ 설정 아이콘 (환경 설정)

#### ⚙️ **설정 화면**
**기본 설정 탭**
- 운동 시간, 휴식 시간, 카운팅 속도 조절
- 자세 정확도 기준: 엄격(95%) / 보통(85%) / 관대(75%)
- 피드백 옵션: 음성 안내, 진동, 실시간 교정 알림

**개인 설정 탭**  
- 신체 정보: 키/몸무게, 운동 경험 수준
- 목표 설정: 주간 운동 목표, 건강 목표

#### 🏃‍♂️ **운동 선택 화면**
- **3가지 운동 종목**: 스쿼트, 푸시업, 플랭크
- 운동별 난이도 및 설명 제공
- 사용자 친화적 선택 인터페이스

#### 📹 **운동 진행 및 자세 분석 화면**
- **실시간 포즈 인식**: 17개 키포인트 스켈레톤 시각화
- **자동 카운팅**: 운동 동작 자동 감지 및 횟수 증가  
- **정확도 표시**: 실시간 신뢰도 87% 수준 제공
- **상태 피드백**: 운동 단계별 안내 ("하강 중", "상승 중")

#### 🏆 **운동 완료 및 기록**
- **체크포인트 달성**: 목표 횟수 완료 시 성취 표시
- **운동 요약**: 운동 시간, 종목별 횟수 통계
- **자동 저장**: 운동 기록 데이터베이스 저장

#### 📊 **운동 기록 화면**  
- **캘린더 뷰**: 날짜별 운동 히스토리 조회
- **신기록 강조**: 개인 최고 기록 달성 시 하이라이트
- **성장 추적**: 꾸준한 운동 습관 시각화

### 🔬 핵심 기술 구현

#### **AI 포즈 인식 시스템**
```
📡 실시간 처리: MediaPipe 기반 30fps 포즈 검출
🎯 정확도: 87% 수준의 안정적인 자세 인식
📐 키포인트: 17개 신체 관절 실시간 추적
🔄 자세 분류: squat_down/squat_up 동작 구분
```

#### **사용자 경험 최적화**
```
🎨 Material Design 기반 직관적 UI
📱 반응형 레이아웃 및 부드러운 애니메이션  
⚡ 모바일 환경 최적화 (TensorFlow Lite)
🔋 배터리 효율성 고려한 경량 처리
```
